# totonoe（整）

Daily yoga &amp; wellness app — 食後の眠気・午後のだるさ・体の硬さを、暮らしのリズムから整えるための個人用習慣アプリ。

`index.html` 1ファイルで動作します（ビルド不要）。ブラウザで開くか、静的ホスティングに置いてホーム画面に追加して使います。

## 機能

- **今日の習慣** — 朝／昼／午後／夜のチェックリスト、連続記録・累計・今月達成率
- **ヨガ** — 朝・昼・夜（曜日別）のおすすめ動画
- **寝たままヨガ（v0.3）** — ベッドや布団に寝たままできるガイド付きフロー
  - 夜の安眠フロー（約10分）／朝の目覚めフロー（約6分）／3分だけフロー
  - 画面内のタイマーがポーズを順に案内。動画は不要
  - 夜・朝のフローを完走すると、今日の習慣（夜ヨガ／朝ヨガ）に自動で記録
- **眠気の対処** — 日中の眠気への対処法と受診の目安
- **記録** — 今月のカレンダー表示
- **同期** — Googleログインで Firestore に保存し、端末間で同期（未ログインでも localStorage で動作）
